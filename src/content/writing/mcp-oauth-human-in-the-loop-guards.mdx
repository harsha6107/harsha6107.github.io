At eParts Services, we shipped two tool-calling interfaces for Peregrin:

1. **In-App Agentic Assistant**: **42 strict function-calling tools** on **Azure AI Foundry** (chosen after benchmarking against LangGraph, CrewAI, and AutoGen), scoring **25/25** on our golden evaluation set.
2. **Stateless MCP Server**: **36 tools** and **156 tests** with **OAuth 2.1**, making Peregrin usable from **Claude, ChatGPT, and VS Code**.

Here are the access-control, write-confirmation, and grounding controls behind both systems.

## 1. Relationship-Based Access Control (ReBAC) & Endpoint-Matched Permissions

Multi-tenant procurement requires checking resource relationships rather than coarse user roles:

- **ReBAC with Permit**: We set up relationship-based access control (ReBAC) with **Permit** and closed a cross-workspace authorization gap among ~15 production bugs fixed in one release cycle.
- **Endpoint-Matched MCP Scopes**: Every tool on the stateless OAuth 2.1 MCP server enforces permissions matched to the underlying backend endpoints.
- **Scoped User Queries**: Scoped *"my orders"* queries strictly to the authenticated user's own purchase orders.

```typescript
// Representative pattern: endpoint-matched ReBAC check before tool execution
const allowed = await permit.check(
  session.userId,
  tool.requiredPermission,
  {
    type: tool.resourceType,
    key: args.resourceId,
    tenant: session.tenantId,
  },
);
```

## 2. Signed 5-Minute Action Tokens for Human-in-the-Loop Writes

Neither the Azure AI Foundry assistant nor the MCP server executes unconfirmed writes:

1. **Stage**: When the model calls a write tool, the server validates permissions and returns a **signed 5-minute action token** alongside a preview of the change.
2. **Confirm**: The write executes only after the user explicitly confirms the action within the 5-minute window, with full audit and query logging.

## 3. Grounding: Open Page Context & Untrusted File Attachments

As chatbot lead, I resolved three grounding failure modes found in production:

- **Removed Ungrounded Chat BOM Import**: Removed a chat BOM import path that never reached the model and caused a High-priority production bug where items were added to the wrong project.
- **Open Page Outranks Conversation Memory**: Made the user's currently open page outrank prior conversation memory when resolving target entities.
- **Read-Only CSV/XLSX Row Search**: Added read-only CSV/XLSX attachment support through a **row-search tool**, treating uploaded file content as untrusted rather than injecting raw spreadsheet text into the prompt.
