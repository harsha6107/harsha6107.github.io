Scoring **25/25 on a golden evaluation set** was our gate to ship Peregrin's 42-tool AI assistant to production users and a customer beta.

Once real users started querying orders, uploading BOM spreadsheets, and switching projects mid-conversation, we needed a systematic way to catch and prevent production failure modes. Here is the evaluation and error-discovery loop we built past the initial 25-case golden set.

## 1. Redacted Export of ~100 Real Conversations per Cycle

We built a pipeline that exports **~100 real production conversations per cycle** with sensitive data redacted, paired with query logging and user feedback signals, so we can inspect actual failure patterns safely.

## 2. Failure-Mode Taxonomy Mapped to Golden Cases

Rather than relying on generic quality scores, we categorized real errors into a **failure-mode taxonomy** and mapped each category directly to new golden test cases:

| Failure Mode | Production Symptom | Fix & Golden Regression Check |
| :--- | :--- | :--- |
| **Ungrounded BOM Import** | Chat BOM import never reached the model and added items to the wrong project | Removed the broken chat BOM import path |
| **Memory vs. Open Page** | Prior conversation history overrode the project currently open in the UI | Made the open page outrank conversation memory |
| **Unscoped Order Lookups** | Queries for *"my orders"* returned workspace-wide purchase orders | Scoped *"my orders"* strictly to the user's own POs |
| **Spreadsheet Attachments** | Raw CSV/XLSX content risked prompt injection or token overflow | Added read-only CSV/XLSX row-search tool treating files as untrusted |

## 3. LLM Rubric Judge Checked Against Human Labels

To scale evaluation without manual grading bottlenecks, we built an **LLM rubric judge** and validated its grading alignment directly against **human labels** before relying on it for automated gating.

## 4. Weekly CI Eval Gate on Chatbot PRs

We wired the expanded golden set and calibrated rubric judge into a **weekly CI eval gate on chatbot pull requests**—alongside a separate **weekly top-5 retrieval eval** for **eParts Brain** (our Snowflake Cortex Search knowledge layer across Granola, Linear, GitHub, and Confluence).
